# A/B Actions OIDC 同 ECS 私有交付运行说明

**仅批准的 `usiboy/testA`、`usiboy/testB` 公开测试仓库。**信任键位于 GitHub OIDC JWKS；工作流临时只读 `GITHUB_TOKEN` 通过精确内部 TLS Host 发给 API，只在请求内存中核源，不进入数据库/Builder 容器。Mac-only GitHub App PEM 不上传。运行现场和失败实证见[验收记录](../tests/2026-10-09-actions-oidc-ab-delivery.md)。

1. ECS 控制 API 为 `ewp-preview-api-20261006.service`；仅 drop-in `oidc-pilot.conf` 设 `EWP_ACTIONS_OIDC_PILOT=1`，无 Token 字面量。数据库已应用 `022_actions_oidc_pilot.sql`。受限数据库备份位于 `/data/ewp-preview-20261006/state/`，启停前先检查 `pg_isready`/迁移版本及旧站。网页 `/v1/hooks/github-actions` 限定两仓库、受众、带数字 ID 的 `sub`、固定工作流/主分支和 GitHub 当前 HEAD；失败只输出稳定错误码，不能因 401/409 反复改变仓库绑定。
2. Root-only Worker `ewp-actions-builder-pilot-20261009.timer` 每 30 秒启动一次 oneshot，`actions-worker.env`（0600）仅含新平台 DB URL 和三个固定存储路径/域名，不带 App PEM、Bootstrap 或 Owner Token。构建只在第二 daemon `unix:///run/ewp-builder-20261007/docker.sock` 的 `PrivateNetwork=yes` 内通过 `runsc --network none`；固定镜像、离线缓存、CPU/内存/PID/100 秒全容器时限与每项目 64 MiB tmpfs 输出卷都必须真实有效。不要改用默认 Docker daemon。
3. **输出卷命名空间：**Worker unit 仍启用 `PrivateTmp`/`ProtectHome`；准备输出卷和受控 build 脚本通过 `nsenter -t 1 -m` 进入宿主 mount namespace，确保第二 daemon 与签名读取的是同一块 64 MiB tmpfs。启动前用 `findmnt -n -o FSTYPE,SIZE -M /data/ewp-builder-20261007/docker/volumes/ewp-builder-{a,b}-output-bounded-20261007/_data` 只读核对。禁止在 Worker 私有 mount namespace 内另挂一个 daemon 看不见的限额并把它当作成功。
4. 有新提交时从 GitHub Actions 自带构建与 API `/github-pushes`（按 Team/Project）核 `actions_oidc → awaiting_isolated_build → preview_candidate/failed`，再用 Owner 访问固定私有 Preview 使 `observedState=preview_ready`；工作台显示原始审计事件/已核源字节，不显示虚构的 CPU/请求数据。Worker 自动生产晋升会重新核 GitHub `main`；公开 API 达到 60 次/小时会留 `preview_candidate`、`last_error_code=branch_head_unavailable`、`attempts=0` 并推迟 2 分钟重试，**不**切别名。只有别名期望代际改变、实际 Host HTTP 正文读回后才算 active。故意失败提交没有 Deployment，不能据此移除旧站。
5. 退出该试点先 `systemctl disable --now ewp-actions-builder-pilot-20261009.timer`，核无进行中的 oneshot，再移除 API 的**试点 drop-in**并 `daemon-reload`、只重启新平台 API；保留审计、原 PGDATA/备份、A/B 旧候选和原 ECS 受限探针。切勿清除默认 Docker 网络或另起同一 SQLite 写者。尚未准入的私仓/新锁文件继续拒绝，不得扩大硬编码 Repo ID 或对 GitHub OIDC 放开通配 `sub`。

**当前已核实的生产读回：**A HTTPS `p-34401f5c05af1079010cb95ee3ec1275.sites.ecp.lingtong.com` 代际 `3/3`，B HTTPS `p-e5123bae12388454bb82fc1590750ab9.sites.ecp.lingtong.com` 代际 `1/1`，两站内部 CA 逐字节 HTML 真读回。B 的 HTTP:80 会被旧站默认处理并 308 跳到旧 IP，**不要当作 B 生产地址**。ECS 工作台已使用 `VITE_SITE_SCHEME=https` 对两项目生成内部 CA HTTPS 链接；首版 HTTP 配置与更早控制台静态目录都保留在新平台目录供定点回退。任何正式公网域名/受信证书仍需独立验收。
